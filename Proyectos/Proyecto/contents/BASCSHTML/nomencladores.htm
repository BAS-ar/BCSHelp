Nomencladores

Esta tabla se utiliza para ingresar códigos de nomencladores y descripciones que luego se asociarán a los bienes para la generación del COT (Código de Operaciones de Traslado) - Web Service.

El Código de Nomenclador tiene una longitud de 6 dígitos y se refiere a la codificación utilizada para identificar los bienes al generar un COT.

Código

Tiene una longitud de 6 dígitos y se refiere a la codificación utilizada para identificar los bienes al generar un COT.

Descripción

Corresponde a la descripción del nomenclador.

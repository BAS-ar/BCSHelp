Gestión de cupones

El proceso de Gestión de cupones permite dado un cupón de tarjeta, modificar el tipo de tarjeta y/o el plan de la misma con los que se registró el cupón en BASCS. 

Se debe identificar el cupón a modificar, para ello se solicitan como datos obligatorios el tipo y número de tarjeta. 

Luego se pueden indicar manualmente la fecha y número de cupón a modificar, o estando posicionado en el número de cupón a través de la búsqueda se pueden observan todos los cupones de esa tarjeta permitiendo seleccionar el que se quiere modificar.

Una vez identificado el cupón, se puede indicar el nuevo tipo de tarjeta y/o el nuevo plan y al grabar se validará que corresponda a un plan válido para la tarjeta indicada, y si se modifica el plan se validará que no sea un plan de diferente moneda.
